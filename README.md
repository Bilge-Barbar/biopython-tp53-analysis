# TP53 Mutation Analysis with Biopython

Welcome to my bioinformatics project! In this project, I used Python to analyze biological sequence data from the NCBI database.

## 🛠️ Tools and Libraries
* **Language:** Python
* **Library:** Biopython
* **Database:** NCBI (National Center for Biotechnology Information)
* **Environment:** Google Colab

## 🧬 Project Overview
The TP53 gene is a very important tumor suppressor gene, and its mutations are seen in many types of cancer. In this project, my goal was to extract and analyze its genetic data.

**What I Did:**
* Fetched nucleotide sequences of the TP53 gene directly from the NCBI database in **FASTA** format.
* Used **Biopython** to read, parse, and process these sequence files easily.
* Performed sequence analysis to understand data structures and basic mutation patterns.
* Wrote clean and understandable Python code to automate the data extraction process.

## 💡 Why This Matters
This project helped me improve my data processing skills. It shows that I can handle biological data formats, use databases, and write Python scripts to solve real bioengineering problems.
